# Лабораторна робота №1 — Авіакомпанія (варіант 9)

**Студент:** Олексієнко Владислав  
**Група:** ІПС-32 (ІС)

## Завдання

Створити консольний додаток для роботи з авіакомпанією:
- ієрархія літаків (пасажирські, вантажні, військово-транспортні);
- підрахунок загальної місткості та вантажопідйомності;
- сортування парку за дальністю польоту;
- пошук літаків за діапазоном споживання палива.

Дані для ініціалізації читаються з файлу `src/main/resources/aircrafts.txt`.

## Структура проєкту

```
ua.kpi.ips32.airline
 ├── app            – точка входу
 ├── company        – клас авіакомпанії
 ├── model          – ієрархія літаків
 └── io             – завантаження з файлу
```

## Як запустити

Потрібні JDK 17+ і Maven.

```bash
mvn test
mvn -q exec:java -Dexec.mainClass="ua.kpi.ips32.airline.app.Main"
```

або:

```bash
mvn package
java -jar target/lab1-airline-1.0-SNAPSHOT.jar
```

## Тести

Використано JUnit 5 і Mockito. Покрито модель, логіку компанії та читання файлу.
